A single kind, funny fortune for the houseplant on the windowsill, written for make.fun's "Fortune in a Pot" bounty — one line, at most 120 characters, judged by a gardener playing judge. Seven variants were tested against the rubric; the winner is a triple prediction built from three concrete windowsill realities: the cat, the sun, and the keeper's watering can. See `VARIANTS.md` for the shortlist and the reasoning.

## Run it

```sh
node main.ts
```

This writes the fortune to `/output/entry.txt`.
